## 0. 핵심 결론 세 가지

1. **몰린 피드에서만 PPO가 맥락에 따라 속도를 바꿉니다.**
   - 지표는 늦추기 지수입니다. 좋은 아이템을 최근에 이해했을 때 느린 속도를 고른 비율에서, 그렇지 않을 때의 비율을 뺀 값입니다.
   - 같은 아이템을 순서만 바꿔서 비교했습니다. 섞인 순서(κ 0)에서는 0.01, 몰린 순서(κ 0.9)에서는 0.18(1M)이었고, 5M 학습에서는 0.34였습니다.
   - 지각 조건(v0), 썸네일 난이도(dν), 관측을 바꿔도 몰림이 있을 때만 나타났습니다.
2. **몰린 피드에서 오래 학습한 PPO는 가장 좋은 손 규칙과 같은 점수입니다.**
   - 5M 학습 PPO 55.3%, 두 속도 규칙 55.7%입니다. 같은 피드끼리 비교한 차이는 −0.4(SE 0.6)입니다.
   - 느린 속도만 쓰는 규칙(51.9%)보다는 높습니다.
   - **PPO가 규칙보다 낫다고 일반화하면 안 됩니다.**
3. **좋은 아이템이 알아보기 어려운 조건(dν = −0.5, 섞인 순서)에서는 PPO가 모든 손 규칙을 넘었습니다.**
   - PPO 45.0%, 가장 좋은 규칙 42.0%입니다(+3.0, SE 0.4, seed 3개 모두 높음).
   - PPO는 화면에서 멈춰 끝까지 읽는 시간이 세션당 16초였습니다. 기본 규칙은 0.3초입니다.

## 1. 방법 (Method에 쓸 내용)

| 항목 | 내용 |
|---|---|
| 알고리즘 | MaskablePPO (Stable-Baselines3 + sb3-contrib). 그 순간 할 수 없는 행동은 마스크로 막음 |
| 과제 | 120초 세션, 피드 100개, dt 0.1초, 스텝 비용 0.01. 행동: 아래/위 스크롤(속도), 멈춤, 열기, 닫기 |
| 신경망 | MLP 256-256, 병렬 환경 8개, n_steps 2048, ent_coef 0.001, γ 0.999, target_kl 0.02, VecNormalize |
| 관측 | **top-k 관측**: 이해한 아이템 중 현재 보상률(공개된 A, λ와 시청 시간으로 계산)이 높은 10개의 값과 위치, 화면 정보, 남은 시간, 이전 행동. 이해하지 않은 아이템의 A, λ와 실제 ν는 넣지 않음 |
| 결정 간격 | **0.5초**(5스텝마다 결정, 그동안 같은 행동 유지). 평가에서도 같은 방식으로 유지 |
| 학습률 | 3e-4에서 0으로 선형 감소 |
| 학습량 | 결정 1M번(기본), 몰린 피드 비교는 5M번 |
| 모델 선택 | 평가와 겹치지 않는 피드(seed 30000~)로 최고 모델을 고름. 5M 학습은 30개 피드로 10만 결정마다 |
| 반복 | 조건마다 학습 seed 3개 |
| 평가 | 학습에 쓰지 않은 피드 100개(seed 10000~10099). PPO는 확률적 행동 |
| 점수 | **상한 대비 %.** 상한은 모든 아이템을 이미 알고 이동·전환 시간이 0일 때의 최대 보상(스텝 비용 포함) |
| 두 속도 | (0.5, 1.5) 화면/초. 초안에 "나중에"로 적힌 값이고, 조건별로만 켬 |
| 몰린 피드 | 두 종류. ① 잠재 유형의 지속성 κ로 새로 생성 ② **같은 아이템을 κ로 재배열**(`feed.reorder_kappa`). ②는 아이템 구성이 같아서 순서 효과만 비교할 수 있음 |

### 비교 규칙

| 규칙 | 행동 | 맞춘 값 |
|---|---|---|
| 기본 규칙 | GreedyKnown: 알려진 최고 보상률 ≥ ρ이면 가서 보고, 아니면 느린 속도로 아래 탐색. ρ 0.6 | 고정 |
| 멈춤 규칙 | 기본 규칙 + 화면에 아직 모르는 카드가 있고 노출이 dwell초 미만이면 멈춤 | ρ ∈ {0.5, 0.6, 0.7}, dwell ∈ {0, 0.25, 0.5, 1.0} |
| 두 속도 규칙 | 멈춤 규칙 + 가장 최근 이해한 아이템의 A가 기준보다 낮으면 빠른 속도 | 위 + A 기준 ∈ {0.8, 1.0} |

- 맞춤은 시험 피드와 다른 피드 30개(seed 20000~)로 했습니다.
- "PPO − 규칙"은 같은 피드끼리의 차이를 피드 100개로 평균한 값입니다. PPO는 seed 3개 평균이고, 괄호 안은 표준오차입니다.
- "가장 좋은 규칙"은 두 규칙 중 시험 피드 점수가 높은 쪽입니다. 규칙에 조금 유리한 비교입니다.

### 늦추기 지수

- 지수 = P(느린 속도 | 마지막 이해 아이템의 A ≥ 0.6) − P(느린 속도 | A < 0.6)
- 아래로 실제 이동한 0.1초 스텝을 셉니다. 아직 이해한 아이템이 없을 때와 바닥에서 막힌 입력은 뺍니다.
- 같은 스텝에 여러 개를 이해하면 목록에서 가장 아래 아이템을 기준으로 합니다.
- 새 결정 스텝만 세어도 값이 같습니다. 그래서 결정 유지 때문에 생긴 값이 아닙니다.

## 5. CHI 초안에 쓸 문장

### 쓸 수 있는 주장 (영어 초안)

- **늦추기:** "On clustered feeds (κ = 0.9, the same item set reordered), PPO chose the slow speed more often while the most recently understood item had a high initial value (slow-down index 0.34 after 5M decisions). On the same items in shuffled order the index was near zero (0.01 after 1M decisions)."
- **점수:** "With 5M training decisions, PPO matched the best hand-tuned context-dependent speed rule (55.3% vs. 55.7% of the reference return; paired difference −0.4, SE 0.6) and exceeded a slow-only rule (51.9%)."
- **규칙 쪽 근거:** "A rule that sped up after a low-value item helped only on clustered feeds (55.7% vs. 51.9% for the slow-only rule), not on shuffled feeds (47.0% vs. 50.9%)."
- **썸네일이 애매한 좋은 콘텐츠:** "When promising items were harder to read from their thumbnails (d_ν = −0.5, shuffled order), PPO exceeded all tuned rules (45.0% vs. 42.0%; +3.0, SE 0.4) by pausing to read the screen (16 s per session vs. 0.3 s for the default rule) and clicking less."

### 쓰면 안 되는 주장

- "PPO가 규칙보다 낫다"는 일반화. 이긴 조건은 C9 섞임 하나입니다.
- "이해 **직후**에 늦춘다". 새 결정만 세도 값이 같고, 직후 첫 결정만 세도 더 커지지 않습니다.
- 주의 분산 +9.8점을 PPO의 이득으로 쓰는 것. 멈춤 규칙과 같습니다.
- 1M 몰린 피드 결과(43.4%, 34.5%)를 PPO의 최종 성능으로 쓰는 것. 학습량 부족이었습니다.

### CHI 초안 v3에서 확인할 곳 (11-24 기준)

- "right after understanding" → "while the most recently understood item had a high initial value"
- PPO 47.8% → 현재 기준값으로 교체. 섞인 피드는 48.3%(한 속도, 1M)이나 50.7%(두 속도, 2M), 몰린 피드는 55.3%(5M)입니다.
- "preserving the item set"은 같은 아이템 재배열(`reorder`) 수치에만 맞습니다. 새로 생성한 κ 피드 수치(34.5%, 45.0%)를 쓸 때는 빼야 합니다.
- Method에 결정 간격 0.5초(평가에서도 유지)와 top-10 관측 설명이 빠져 있습니다.

## 6. B9 — 몰린 피드 조건 7개를 5M으로 (11-26 진행 중)

- 대상: `b7-recent-k0.9`, `b8-*` 5개, `c9-dnu-k0.9`. 각각 `-5m`을 붙인 이름입니다.
- 1M 조건과 모델 설정은 같고, 학습만 B6와 같습니다. 결정 5M번, 최고 모델은 피드 30개로 10만 결정마다 고릅니다.
- 결과가 나오면 이 장에 표를 넣습니다.

## 7. 한계 (Limitations에 쓸 내용)

- 학습 seed는 조건마다 3개입니다. 늦추기 지수의 seed 간 차이가 큽니다(예: 0.05~0.25). 방향은 몰린 피드에서 모든 seed가 같습니다.
- 5M에서도 학습 곡선이 오르고 있어 수렴하지 않았습니다.
- 비교 규칙은 작은 격자에서 맞췄습니다. 더 좋은 규칙이 있을 수 있습니다.
- 두 속도 값(0.5, 1.5)과 κ 0.9는 실험용 설정입니다. 합의 설정은 한 속도(0.5)입니다.
- 결정 간격 0.5초는 학습을 위한 선택입니다. 사람의 결정 간격과 맞춘 값이 아닙니다.
