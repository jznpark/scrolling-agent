- 규칙은 느린 속도(0.5)만 쓰므로 한 속도와 두 속도 조건에서 같은 값입니다.
- 결정적 행동 PPO는 모든 조건에서 확률적 행동보다 2~9점 낮습니다(11-05와 같은 경향).
- κ 0.9 새로 생성 피드는 피드마다 좋은 아이템 수가 크게 달라 편차가 큽니다. 같은 아이템 재배열(`reorder`)에서는 규칙 편차가 10.7로 줄었습니다.

**해석**
- **A2:** 느린 속도만 있을 때 κ 0.9 PPO 점수는 38.9%였고, 빠른 속도를 추가하자 34.5%로 내려갔습니다. 몰린 피드에서는 선택지가 늘어난 만큼 1M 학습으로는 부족합니다. 빠른 속도로 지나치며 이해 수가 64개에서 39개로 줄었습니다.
- **A3:** κ 0에서는 학습을 2M으로 늘리자 규칙을 따라잡았습니다(48.2 → 50.7). PPO는 이해를 더 많이 하고(68 대 59) 클릭은 더 적게 했습니다(23 대 29).
- **A4:** 아이템이 같으면 규칙 점수는 순서와 상관없습니다(10-27 κ 실험과 같은 결과). PPO만 5점 떨어지므로, 몰린 순서를 다루는 학습이 아직 부족한 것입니다. κ 0.9에서 PPO는 되돌아가 열기를 7회 해서 규칙보다 훨씬 많이 했습니다.
- **A1:** 잔여 처리는 규칙 점수를 0.5~1.5점 올렸습니다. 되돌아가 열기는 2~3회였습니다. PPO는 이해 수만 늘고(67 → 72) 되돌아가지 않아, 점수가 오르지 않았습니다.

## 3. 늦추기 지수 (A5)

지수 = P(느린 속도 | 마지막 이해 아이템 A ≥ 0.6) − P(느린 속도 | A < 0.6). 아래로 실제 이동한 0.1초 스텝 기준이며, seed 3개 평균입니다(괄호는 seed별 값).

| 조건 | 전체 스텝 (11-09 정의) | 새 결정만 | 이해 직후 첫 결정 | 이해 후 1초 이내 | 빠른 속도 비율 |
|---|---|---:|---:|---:|---:|
| `speed2` (κ 0) | −0.001 (−0.007 / −0.007 / 0.010) | −0.004 | 0.032 | 0.069 | 0.48 |
| `speed2-k0.9` | **0.132** (0.183 / 0.099 / 0.115) | 0.131 | 0.179 | 0.164 | 0.68 |
| `speed2-2m` (κ 0) | −0.007 (−0.006 / −0.012 / −0.002) | −0.009 | 0.073 | 0.080 | 0.48 |
| `reorder-k0` | 0.008 (−0.025 / −0.008 / 0.058) | 0.013 | 0.045 | 0.046 | 0.50 |
| `reorder-k0.9` | **0.180** (0.253 / 0.236 / 0.051) | 0.181 | 0.208 | 0.198 | 0.53 |
| 11-09 보고 κ 0 / κ 0.9 | 0.014 / 0.169 | — | — | — | — |

- 다시 구현한 지수는 11-09 값과 같은 방향과 크기입니다. κ 0은 둘 다 0 근처이고, κ 0.9 seed별 값은 0.18 / 0.10 / 0.12와 0.20 / 0.11 / 0.20입니다.
- 한 속도 조건 `a-base`는 지수가 0입니다. 늦출 수 있는 속도가 없으니 그래야 맞고, 점검용으로 넣었습니다.
- 동시 이해 제외 지수는 전체 지수와 0.01 이내라 표에서 뺐습니다(`runs/speed_context/summary.md`).
- **"이해 직후"라고 쓰면 안 되는 이유:** 새 결정만 세어도 값이 그대로입니다. 결정 유지(0.5초) 때문에 생긴 값이 아닙니다. 다만 직후 첫 결정에서 조금 더 커질 뿐 전체 경향과 같습니다. "좋은 아이템을 최근에 이해했을 때 더 자주 느리게"가 맞는 표현입니다.
- κ 0에서도 직후 첫 결정과 1초 이내 지수는 0.03~0.08로 작지만 양수입니다. 좋은 아이템 바로 다음에 잠깐 느려지는 반응은 몰림과 상관없이 조금 있습니다.
