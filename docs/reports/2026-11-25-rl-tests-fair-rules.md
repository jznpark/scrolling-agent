# B·C 테스트 정리 — 더 강한 규칙과 다시 비교

- 작성: 2026-11-25 · 박준호 (Claude Code로 실행)
- 브랜치: `feature/rl-tests-a` · 스크립트 `scripts/experiments/fair_rules.py`
- 이유: 파이프라인의 규칙(GreedyKnown, ρ 0.6)은 멈춰 읽지 않고 느린 속도만 씁니다. PPO가 이 규칙을 이긴 조건에서, 그 이득이 "규칙에 없는 선택지" 때문인지 확인해야 했습니다.

## 0. 결론

1. **PPO가 가장 좋은 손 규칙까지 넘은 조건은 하나입니다.** 좋은 아이템이 알아보기 어려운 섞인 피드(C9 `c9-dnu-k0`)에서 +3.0점이었습니다(SE 0.4).
2. **같은 아이템 몰린 피드의 5M PPO(B6)는 가장 좋은 두 속도 규칙과 같습니다.** 55.3% 대 55.7%입니다. 느린 속도 규칙(51.9%)보다는 높습니다.
3. **주의 분산(C10)에서 PPO가 앞섰던 +9.8점은 멈춰 읽기 때문이었습니다.** 멈춤 규칙과는 같습니다(41.1% 대 41.1%).
4. **두 속도 규칙은 몰린 피드에서만 이득입니다.** "최근 이해한 아이템 가치가 낮으면 빠르게"라는 규칙의 점수는 다음과 같습니다.
   - 같은 아이템 섞인 순서: 47.0%(느린 규칙 50.9%보다 낮음)
   - 같은 아이템 몰린 순서: 55.7%(느린 규칙 51.9%보다 높음)
   - **몰림이 있을 때만 맥락에 따라 속도를 바꾸는 것이 합리적이라는 근거입니다.** PPO의 늦추기 지수가 몰린 피드에서만 커지는 것과도 맞습니다.
5. **1M 학습 PPO는 몰린 피드 조건 전부에서 두 속도 규칙보다 8~15점 낮습니다.** 몰린 피드 조건은 B7, B8, C9 κ 0.9입니다. 같은 조건을 5M으로 학습하면 차이가 사라졌습니다(B6). 이 조건들도 5M 학습이 필요합니다.

## 1. 규칙

| 이름 | 행동 | 맞춘 값 (피드 20000~20029, 30개) |
|---|---|---|
| 멈춤 규칙 | GreedyKnown: 알려진 최고 보상률 ≥ ρ이면 가서 봄. 아니면 아래로 탐색하되, 화면에 아직 모르는 카드가 있고 노출이 dwell초 미만이면 멈춤 | ρ ∈ {0.5, 0.6, 0.7}, dwell ∈ {0, 0.25, 0.5, 1.0} |
| 두 속도 규칙 | 멈춤 규칙과 같고, 탐색 중 가장 최근 이해한 아이템의 A가 기준보다 낮으면 빠른 속도 사용 | 위 + A 기준 ∈ {0.8, 1.0} |

- 평가는 PPO와 같은 시험 피드 100개(10000~)로 했습니다.
- "PPO − 규칙"은 같은 피드끼리의 차이입니다(PPO는 seed 3개 평균, 확률적 행동).
- 기본 피드에서 A는 보통 아이템이 약 0.5, 좋은 아이템이 약 1.5입니다. 그래서 A 기준 0.8~1.0이 두 종류를 나눕니다.

## 3. 늦추기 지수 모음 (seed 3개 평균)

| 피드 | 1M | 5M |
|---|---:|---:|
| 같은 아이템 κ 0 (`reorder-k0`) | 0.008 | – |
| 같은 아이템 κ 0.9 (`reorder-k0.9`) | 0.180 | 0.339 |
| 새로 생성 κ 0.9 (`speed2-k0.9`) | 0.132 | 0.284 |
| + 최근 맥락 κ 0 / κ 0.9 (B7) | −0.047 / 0.115 | – |
| B8 지각 조건 5개 (κ 0.9) | 0.107 ~ 0.162 | – |
| dν −0.5, κ 0 / κ 0.9 (C9) | −0.041 / 0.183 | – |

**늦추기는 κ 0.9에서만 나타납니다.** 지각 조건(v0), 썸네일 난이도(dν), 관측(최근 맥락)을 바꿔도 마찬가지이고, 학습을 오래 할수록 커집니다.

## 4. CHI 초안에 주는 의미

- **쓸 수 있는 주장:**
  - 클러스터된 피드에서 학습한 PPO는 높은 가치의 아이템을 이해한 뒤 더 자주 느린 속도를 고릅니다(5M: 0.34).
  - 같은 학습량이면 손으로 만든 가장 좋은 맥락 속도 규칙과 같은 보상을 얻습니다(55.3% vs. 55.7%).
  - 같은 아이템을 섞으면 이 경향과 이득이 모두 사라집니다.
- **새로 쓸 수 있는 결과:** 좋은 콘텐츠의 썸네일이 애매하면(dν < 0) PPO는 멈춰 읽는 전략으로 모든 손 규칙을 넘습니다(+3.0점).
- **쓰면 안 되는 주장:**
  - "PPO가 규칙보다 낫다"를 일반화하면 안 됩니다.
  - 주의 분산 +9.8점을 PPO의 이득으로 쓰면 안 됩니다. 그 이득은 멈춰 읽기에서 나왔고, 멈춤 규칙과 같습니다.

## 5. 남은 일

1. **몰린 피드 조건을 5M으로 학습합니다.** 대상은 B8 5개, C9 κ 0.9, B7 κ 0.9입니다. 조건마다 약 25~30분 걸립니다(11-25 실측: 6개 run 동시 학습, 3.3M→5M에 26분).
2. **C9 섞인 피드를 확인합니다.** seed를 늘리고(5개 이상), PPO가 멈춰 읽는 패턴을 시각화합니다.
3. **추정 오차(C10)에서 PPO가 약한 원인을 확인합니다.**
4. **D(파라미터 조건부 PPO)를 진행할지 결정합니다.** 팀 결정이 필요합니다.
