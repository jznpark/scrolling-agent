# 추가 RL 테스트 B6 — 몰린 피드에서 오래 학습하기

- 작성: 2026-11-25 · 박준호 (Claude Code로 실행)
- 브랜치: `feature/rl-tests-a` · 조건 코드 194220f
- 질문: 몰린 피드(κ 0.9)에서 PPO가 규칙보다 낮았던 것(A 테스트)은 학습량이 부족해서인가?

## 0. 한눈에

1. **같은 아이템을 몰리게 배열한 피드에서, 5M 학습한 PPO가 처음으로 규칙보다 높았습니다.**
   - PPO 55.3 ± 8.9%, 규칙 51.5 ± 10.7%
   - 같은 피드끼리 비교하면 PPO가 +3.8점 높습니다(SE 0.9). seed 3개 모두 높았습니다(+5.1 / +3.0 / +3.4).
   - 1M 학습에서는 −8.1점이었습니다.
2. **κ 0.9로 새로 만든 피드에서도 규칙과의 차이가 거의 사라졌습니다.**
   - PPO 43.6%, 규칙 45.0%. 같은 피드끼리 비교하면 −1.5점(SE 0.9)입니다.
   - 1M 학습에서는 −10.6점이었고, 11-09의 2M 결과는 39.0%였습니다.
3. **늦추기 지수가 1M 학습 때보다 두 배쯤 커졌습니다.**
   - 같은 아이템 몰린 배열: 0.18 → 0.34
   - 새로 만든 몰린 피드: 0.13 → 0.28
   - 학습을 오래 할수록 "좋은 아이템을 이해한 뒤 느리게"가 더 뚜렷해지고, 점수도 함께 올랐습니다.
4. **5M에서도 학습 곡선이 아직 오르고 있습니다.** 더 길게 학습하면 더 오를 수 있습니다.

→ A 테스트에서 몰린 피드의 PPO가 낮았던 주된 원인은 **학습량 부족**이었습니다.

## 1. 설정

| 조건 | 피드 | 학습 | 대조군(A 테스트, 1M) |
|---|---|---|---|
| `b6-k0.9-5m` | κ 0.9로 새로 만든 피드 | 결정 5M | `speed2-k0.9` |
| `b6-reorder-k0.9-5m` | 같은 아이템을 κ 0.9로 재배열 | 결정 5M | `reorder-k0.9` |

- 나머지 설정은 A 테스트와 같습니다: 두 속도 (0.5, 1.5), topk 관측, 결정 간격 0.5초, 학습률 3e-4 → 0 선형 감소, seed 3개.
- **모델 선택:** 평가와 겹치지 않는 피드 30개(seed 30000~)로 10만 스텝마다 골랐습니다.
- **평가:** 학습에 쓰지 않은 피드 100개(seed 10000~)로 했고, PPO는 확률적 행동입니다.
- **학습 중단과 재개:** 11-11 밤에 3.2~3.3M 지점에서 PC 문제로 학습이 멈췄고, 11-25에 마지막 저장 지점부터 이어서 5M까지 학습했습니다(`--resume`). 이어서 학습한 구간은 새 학습 피드를 씁니다(seed +500). 평가 피드와는 겹치지 않습니다.

## 2. 점수 (상한 대비 %, 피드 100개 × seed 3개)

| 조건 | PPO | 규칙(ρ 0.6) | 같은 피드 차이 (PPO − 규칙) | PPO가 이긴 피드 | 결정적 PPO |
|---|---:|---:|---:|---:|---:|
| `reorder-k0.9` (1M) | 43.4 ± 13.1 | 51.5 ± 10.7 | −8.1 (SE 1.3) | 27% | 35.6 |
| **`b6-reorder-k0.9-5m`** | **55.3 ± 8.9** | 51.5 ± 10.7 | **+3.8 (SE 0.9)** | **65%** | 54.4 |
| `speed2-k0.9` (1M) | 34.5 ± 14.9 | 45.0 ± 15.8 | −10.6 (SE 1.0) | 12% | 25.3 |
| **`b6-k0.9-5m`** | **43.6 ± 13.8** | 45.0 ± 15.8 | **−1.5 (SE 0.9)** | 40% | 39.9 |
| 참고: `speed2-2m` (κ 0, 2M) | 50.7 ± 4.5 | 50.8 ± 4.3 | −0.2 (SE 0.5) | 50% | 48.6 |

- **같은 피드 차이:** 피드마다 (PPO seed 3개 평균 − 규칙)을 구해 피드 100개로 평균한 값입니다. 괄호 안은 그 표준오차입니다.
- **ρ를 다시 고른 규칙:** 같은 아이템 몰린 배열에서 51.9%입니다. PPO는 이보다도 높습니다.
- **결정적 행동:** 5M 학습에서는 확률적 행동과의 차이가 1~4점으로 줄었습니다. 1M 학습에서는 8~9점이었습니다.

### 행동 비교 (같은 아이템 몰린 배열, 에피소드 평균)

| | 규칙 | PPO 1M | PPO 5M |
|---|---:|---:|---:|
| 이해한 아이템 수 | 58.0 | 42.6 | 47.2 |
| 클릭 | 29.1 | 27.6 | 26.4 |
| 되돌아가 열기 | 0.2 | 7.0 | 5.8 |
| 시청 시간(초) | 64.8 | 63.0 | 66.7 |
| 목록에서 멈춘 시간(초) | 0.0 | 8.3 | 10.4 |
| 빠른 속도 비율 | 없음(느린 속도만) | 0.53 | 0.47 |

- PPO는 규칙보다 적게 이해하고 적게 클릭하는데도 더 오래 시청합니다. 덜 보고 더 잘 고르는 셈입니다.
- 좋은 구간에서는 멈추거나 느리게 가고, 나쁜 구간은 빠르게 지나갑니다(3장 지수 참고).
- 지나친 좋은 아이템으로 되돌아가 여는 행동도 규칙보다 훨씬 많습니다.

## 3. 늦추기 지수

지수 = P(느린 속도 | 마지막 이해 아이템 A ≥ 0.6) − P(느린 속도 | A < 0.6). 아래로 실제 이동한 0.1초 스텝 기준입니다.

| 조건 | 전체 스텝 (seed별) | 새 결정만 | 이해 직후 첫 결정 | 1초 이내 | 빠른 속도 비율 |
|---|---|---:|---:|---:|---:|
| `reorder-k0.9` (1M) | 0.180 (0.253 / 0.236 / 0.051) | 0.181 | 0.208 | 0.198 | 0.53 |
| **`b6-reorder-k0.9-5m`** | **0.339** (0.452 / 0.284 / 0.281) | 0.349 | 0.287 | 0.327 | 0.47 |
| `speed2-k0.9` (1M) | 0.132 (0.183 / 0.099 / 0.115) | 0.131 | 0.179 | 0.164 | 0.68 |
| **`b6-k0.9-5m`** | **0.284** (0.117 / 0.348 / 0.387) | 0.295 | 0.292 | 0.296 | 0.53 |

- 지수가 seed 6개 모두에서 양수이고, 1M 학습 때보다 커졌습니다.
- 이번에도 새 결정만 세면 전체 지수와 같습니다. 이해 직후 첫 결정만 세면 오히려 조금 작습니다. 그래서 "이해 직후의 반응"보다는 "좋은 아이템을 최근에 이해한 동안 계속 느리게"로 쓰는 것이 맞습니다.

## 4. 학습 곡선 (모델 선택 피드 30개의 평균 누적 보상, 1M 구간별)

| run | 0–1M | 1–2M | 2–3M | 3–4M | 4–5M | 최고 시점 |
|---|---:|---:|---:|---:|---:|---:|
| `b6-k0.9-5m` s0 / s1 / s2 | 15.6 / 7.8 / 4.5 | 19.7 / 23.1 / 15.5 | 24.7 / 30.6 / 20.9 | 30.0 / 33.3 / 33.8 | 36.0 / 40.0 / 38.1 | 5.0M / 4.7M / 5.0M |
| `b6-reorder-k0.9-5m` s0 / s1 / s2 | 15.8 / 20.2 / 19.9 | 38.3 / 37.6 / 37.8 | 40.2 / 42.7 / 42.1 | 41.3 / 44.3 / 47.5 | 50.1 / 47.4 / 50.7 | 5.0M / 4.9M / 5.0M |

- 모든 run이 마지막 구간에서 가장 높습니다. **아직 수렴하지 않았습니다.**
- 마지막 구간의 상승에는 학습률이 0으로 줄어드는 효과도 섞여 있을 수 있습니다.

## 5. 해석과 주의

- **CHI 초안에 쓸 수 있는 문장:** "With enough training (5M decisions), PPO exceeded the slow-speed rule on clustered feeds with the same items (55.3% vs. 51.5%, paired +3.8 ± 0.9 points), while slowing down more often after understanding a high-value item (index 0.34)."
- **규칙은 느린 속도만 씁니다.** PPO가 앞선 부분은 '나쁜 구간을 빠르게 지나가기'라는, 규칙에 없는 선택지에서 나왔을 수 있습니다. 공정하게 비교하려면 빠른 속도를 쓰는 규칙(예: 최근 이해한 A가 낮으면 빠르게)도 필요합니다. → 다음 후보
- **κ 0.9 새로 생성 피드:** 피드마다 좋은 아이템 수가 크게 달라 편차가 큽니다. 그래서 같은 아이템 재배열 결과가 더 깨끗한 비교입니다.
- **seed가 3개뿐입니다.** 방향은 모든 seed에서 같습니다.
- **같은 학습량의 κ 0 대조군(5M)은 아직 없습니다.** κ 0에서는 2M에서 이미 규칙과 같았습니다.
