# 추가 RL 테스트 B9 — 몰린 피드 조건 7개를 5M으로 다시 학습

- 작성: 2026-11-26 · 박준호 (Claude Code로 실행)
- 브랜치: `feature/rl-tests-a` · 조건 코드 cc8d53f (`B9_LONG`, 이름 끝 `-5m`)
- 질문: B7·B8·C9의 몰린 피드 조건에서 1M PPO가 규칙보다 8~15점 낮았던 것은, B6처럼 학습량이 부족해서인가?

## 0. 한눈에

1. **열세의 대부분은 학습량 때문이었습니다.**
   - 5M으로 학습하자 7개 조건 모두 점수가 올랐습니다. 상승폭은 +7.2 ~ +12.6점입니다.
   - 가장 좋은 규칙과의 차이는 −8.8 ~ −14.8점에서 −5.2 ~ +0.9점으로 줄었습니다.
2. **5M PPO는 7개 조건 모두에서 느린 속도 규칙보다 높았습니다.** 차이는 +1.5 ~ +4.5점입니다.
3. **두 속도 규칙과 비교하면 같은 수준이거나 조금 낮습니다.**
   - 같은 수준: C9 κ 0.9(−0.2, SE 1.4), B8 v0 1·빠른 속도 1.0(+0.9, SE 0.5)
   - 2~5점 낮음: 나머지 5개 조건
   - B8 v0 1·빠른 속도 1.0은 PPO가 두 규칙을 모두 넘은 두 번째 조건입니다. seed 3개 모두 두 속도 규칙보다 높았지만, 차이가 SE의 2배가 안 되어 "같은 수준"으로 보는 것이 안전합니다.
4. **늦추기 지수는 21개 run 모두 양수였습니다.**
   - 7개 조건 중 6개에서 1M보다 커졌습니다.
   - 좋은 아이템이 알아보기 어려운 C9 κ 0.9에서 가장 컸습니다(0.45).
5. **관측에 최근 맥락을 넣어도(B7) 5M에서도 이득이 없었습니다.**
   - 점수는 53.4%로, 넣지 않은 B6 55.3%보다 조금 낮습니다.
   - 학습 곡선이 오르는 속도도 B6와 같았습니다.

## 1. 설정

- 대상은 1M 학습에서 규칙보다 낮았던 몰린 피드 조건 7개입니다.
  - `b7-recent-k0.9`
  - `b8-v0.5-f1.5`, `b8-v2-f1.5`, `b8-v0.5-f1`, `b8-v1-f1`, `b8-v2-f1`
  - `c9-dnu-k0.9`
- 모델 설정은 1M 조건과 같고, 학습만 B6와 같게 바꿨습니다.
  - 결정 5M번, 학습률 3e-4 → 0 감소
  - 최고 모델은 평가와 겹치지 않는 피드 30개(seed 30000~)로 10만 결정마다 골랐습니다.
- 모든 조건이 같은 아이템을 κ 0.9로 재배열한 피드이고, 속도는 두 개입니다.
- seed 3개 × 7조건 = 21개 run입니다. 11-26 09:34~17:00에 2·2·3조건씩 학습했습니다. 중단된 run은 없었습니다.
- 평가는 학습에 쓰지 않은 피드 100개(seed 10000~)로 했고, PPO는 확률적 행동입니다.
- 규칙 두 가지는 피드 20000~20029에서 맞춘 뒤 같은 시험 피드로 평가했습니다(`fair_rules.py`). 1M 비교와 같은 규칙입니다.
  - 느린 속도 규칙: GreedyKnown + 멈춤
  - 두 속도 규칙: 최근 이해한 A가 낮으면 빠르게

## 6. 해석과 주의

- **B6의 결론이 다른 몰린 피드 조건에도 맞습니다.** 1M 열세는 학습량 때문이었습니다. 5M PPO는 느린 속도 규칙을 넘고, 두 속도 규칙에는 근접합니다.
- **두 속도 규칙이 느린 규칙보다 크게 앞서는 조건일수록, PPO가 두 속도 규칙에 못 미칩니다.**

  | 조건 | 두 속도 규칙 − 느린 규칙 | PPO 5M − 두 속도 규칙 |
  |---|---:|---:|
  | `b8-v0.5-f1.5` | +9.1 | −5.2 |
  | `b8-v0.5-f1` | +6.9 | −2.4 |
  | `b8-v2-f1` | +5.9 | −4.0 |
  | `b8-v2-f1.5` | +4.1 | −2.2 |
  | `b7`, `c9`, B6 | +3.8 | −2.3, −0.2, −0.4 |
  | `b8-v1-f1` | +1.6 | +0.9 |

  - "최근 아이템이 별로면 빠르게"라는 단순 규칙이 큰 이득을 주는 조건에서는, PPO가 5M에서도 그 규칙을 완전히 찾지 못했습니다.
  - 학습 곡선이 아직 오르고 있으므로, 더 학습하면 차이가 줄 수 있습니다.
- **C9 κ 0.9:** 알아보기 어려운 좋은 아이템이 몰려 있으면, PPO는 가장 강하게 늦추고(0.45) 가장 좋은 규칙과 같은 점수를 냅니다. 섞인 순서(C9 κ 0)에서는 1M PPO가 모든 규칙을 넘었습니다. 두 결과를 합치면, 썸네일이 애매한 좋은 콘텐츠에서 학습 정책의 장점이 가장 분명합니다.
- **주의:**
  - seed는 3개입니다.
  - "가장 좋은 규칙"은 두 규칙 중 시험 피드 점수가 높은 쪽을 고른 값이라 규칙에 조금 유리합니다.
  - 같은 학습량(5M)의 κ 0 대조군은 없습니다.
