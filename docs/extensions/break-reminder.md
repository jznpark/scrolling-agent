# 그만 보기 알림 — Task #3

작성: 황도현 · 작업 브랜치: `feature/break-reminder`

`feature/web-demo`의 `baeee8af2b5f30b5d9abd6f514e8388965bd0955`에서 시작한 웹 데모 확장입니다.
일정 시간마다 잠시 멈추고 계속 볼지 선택하게 합니다. 기본값은 **꺼짐**입니다.

## 아이디어와 첫 버전의 범위

피드를 계속 넘기다 보면 얼마나 오래 봤는지 놓치기 쉽습니다. 알림이 사용 시간을 보여 주고,
사용자가 **계속 보기** 또는 **이번 세션 그만 보기**를 선택할 기회를 제공합니다.

이 버전은 데모의 재생과 세션을 제어합니다. 모델의 보상·관측·DDM·정책을 변경하지 않으며,
알림을 무시하거나 수락하는 사람의 확률 모델을 구현한 것은 아닙니다. 실제 사용자의 습관 개선 효과를 검증한 것도 아닙니다.

## 설정

⚙ 설정 → **그만 보기 알림**에서 값을 바꾸고 **적용하고 다시 시작**을 누릅니다.

| 설정 | 화면 이름 | 기본값 |
|---|---|---|
| `reminder.enabled` | 그만 보기 알림 켜기 | `false` (꺼짐) |
| `reminder.after_seconds` | 처음 알릴 사용 시간 (초) | `30.0` |
| `reminder.snooze_seconds` | 계속 보기 후 다시 알릴 간격 (초) | `15.0` |

- 시간은 **시뮬레이션의 경과 시간**입니다. 목록 탐색·콘텐츠 시청·여닫는 시간을 모두 합칩니다. 실제 벽시계 시간과 다릅니다.
- 알림에 응답하는 동안에는 시뮬레이션 시간과 보상이 변하지 않습니다.
- 시간 설정은 양의 유한수만 허용합니다. `dt`의 배수가 아니면 그 시각 이상인 첫 스텝에서 알립니다.
- 전체 세션이 끝나는 시각과 알림이 겹치면 세션 종료가 우선입니다.
- 기존 데모처럼 마지막 설정은 브라우저에 저장됩니다. **상황 → 기본**을 선택하면 알림도 다시 꺼집니다.

## 직접 실행하기

기존 가이드대로 설치한 Python 환경에서 이 브랜치의 저장소 루트를 엽니다.

```powershell
python scripts/serve.py --port 8140
```

1. `http://127.0.0.1:8140/`을 엽니다.
2. 상황에서 **30초 뒤 그만 보기 알림 [확장]**을 고릅니다.
3. 정책 `greedy`, ρ `0.6`, seed `10000`으로 재생합니다. dwell `0.5`는 이 정책에서 미사용입니다.
4. 30초에 알림이 뜨고 재생·한 스텝 버튼이 비활성화됩니다.
5. **계속 보기**를 누르면 자동으로 이어서 재생하고, 45초에 다시 묻습니다.
6. **이번 세션 그만 보기**를 누르면 그 시점의 점수와 콘텐츠 상태를 남긴 채 종료합니다.
7. **다시 시작 (R)**을 누르면 시간·알림 횟수·종료 상태가 초기화됩니다.

30초 알림 장면으로 바로 이동하는 주소:

```text
http://127.0.0.1:8140/?scenario=take_break&policy=greedy&rho=0.6&dwell=0.5&seed=10000&skip=600&speed=10&compact=1
```

`skip=600`으로 60초 진행을 요청해도 서버가 첫 알림인 30초에서 멈춥니다.
빠른 확인은 `speed=200`으로 바꾸면 됩니다. 재생 속도는 알림이 발생하는 시뮬레이션 시각에 영향을 주지 않습니다.
`human` 모드에서도 한 스텝·방향키·카드 열기 입력에 같은 알림 규칙이 적용됩니다.

여러 환경 브랜치를 보여 주는 `serve_branches.py`에서도 사용할 수 있습니다.
알림 설정은 웹 데모 전용으로 관리하므로 다른 브랜치의 `scrolling_agent.Config`에 새 필드를 요구하지 않습니다.

## 간단한 결과

같은 피드 **1개(seed 10000)**, `greedy`, ρ=0.6, 전체 세션 상한 120초로 실행했습니다.
아래 선택 순서는 검증을 위해 미리 정한 동작이며, 실제 사람의 응답 데이터가 아닙니다.

| 조건 / 선택 | 종료 시각 | 알림 횟수 | 실제 콘텐츠 시청 시간 | 열어 본 횟수 | 얻은 재미 |
|---|---:|---:|---:|---:|---:|
| 알림 꺼짐 | 120.0초 | 0 | 58.5초 | 31 | 45.90 |
| 첫 알림에서 그만 보기 | 30.0초 | 1 | 10.5초 | 9 | 6.34 |
| 한 번 계속 보기, 다음 알림에서 그만 보기 | 45.0초 | 2 | 21.5초 | 11 | 16.54 |
| 매번 계속 보기 | 120.0초 | 6 | 58.5초 | 31 | 45.90 |

**계속 보기를 반복하면 알림을 끈 경우와 같은 결과**로 끝납니다. 그만 보기를 선택한 경우에만 세션이 일찍 끝납니다.
짧은 세션은 누적 보상이 작으므로 이 표의 점수를 이용 효율이나 건강 효과의 우열로 해석하지 않습니다.

아래 **행동 비교**는 기존 모델을 세션 끝까지 평가하는 기능입니다. 알림 응답은 평가 대상이 아니며,
알림이 켜졌을 때 이를 설명하는 안내를 표시합니다. 현재 알림의 결과는 **상태 표·알림 횟수·일어난 일**에서 확인합니다.

결과 재현 예시(저장소 루트에서 Python 실행, 패키지 설치 상태):

```python
from webdemo.server import Session

cases = [("off", False, []), ("stop_first", True, ["stop"]),
         ("continue_once", True, ["continue", "stop"]), ("always_continue", True, [])]
for name, enabled, choices in cases:
    s = Session(10000, {"reminder.enabled": enabled}, {"name": "greedy", "rho": 0.6}, None)
    while not s.done:
        s.step(600)
        if s.reminder.pending:
            s.respond_reminder(choices.pop(0) if choices else "continue")
    result = s.state([])
    print(name, result["t"], result["time_by_mode"]["WATCH"], result["n_clicks"], result["return"])
```
