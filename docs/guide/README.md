# Scrolling Agent 웹 데모 사용 가이드

브라우저에서 스크롤 에이전트가 피드를 넘기고, 알아보고, 열어 보는 모습을 실시간으로 보고 직접 조작해 보는 도구의 사용 설명서입니다.

| 장 | 내용 | 상태 | 작성 |
|---|---|---|---|
| 1 | 처음 한 번 준비하기 | 작성됨 | 박준호 |
| 2 | 실행하고 페이지 열기 | 작성됨 | 박준호 |
| 3 | 화면 각 부분의 역할 | **작성 필요** | 팀원 (3장 표에 이름 적기) |
| 4 | 이 문서에 추가하는 방법 | 작성됨 | 박준호 |

> 처음 보는 분은 1장 → 2장 순서대로 따라 하면 됩니다. 3장을 쓰실 분은 4장을 먼저 읽어 주세요.

---

## 1. 처음 한 번 준비하기

Windows PowerShell 기준입니다. VS Code에서 **터미널 → 새 터미널**(`` Ctrl + ` ``)을 열고 순서대로 실행합니다.

```powershell
# 1) 코드 받기 (처음 한 번)
git clone https://github.com/jznpark/scrolling-agent.git C:\Workspace\scrolling-agent
cd C:\Workspace\scrolling-agent
git switch feature/web-demo

# 2) 가상환경 만들고 설치 (처음 한 번, 몇 분 걸림)
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e ".[dev]"

# 3) 잘 설치됐는지 확인 — 마지막 줄에 "passed"가 나오면 성공
pytest
```

- 새 터미널을 열 때마다 `.\.venv\Scripts\Activate.ps1`을 다시 실행해야 합니다. 줄 앞에 `(.venv)`가 보이면 켜진 상태입니다.
- `Activate.ps1`에서 "스크립트를 실행할 수 없습니다" 오류가 나면 먼저 아래를 실행하세요.
  ```powershell
  Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
  ```
- 이미 받아 둔 경우에는 최신으로만 바꾸면 됩니다: `git switch feature/web-demo` → `git pull`

## 2. 실행하고 페이지 열기

### 2.1 내 PC에서 실행하기

```powershell
cd C:\Workspace\scrolling-agent
.\.venv\Scripts\Activate.ps1
python scripts\serve_branches.py --open
```

터미널에 아래처럼 나오면 실행된 것입니다. `--open`을 붙이면 브라우저가 자동으로 열립니다.

```text
  /b/1/  feature/ppo @ 39580c0
  /b/2/  feature/value-error @ 3a53ef7
  /b/3/  feature/offscreen-residual @ a57c720
  /b/4/  feature/attention-split @ 445b875
Comparison page: http://127.0.0.1:8000  - Ctrl+C to stop all
```

- 자동으로 안 열리면 브라우저 주소창에 **http://127.0.0.1:8000** 을 입력합니다.
- 이 터미널은 **켜 둔 채로** 두어야 페이지가 동작합니다. 끌 때는 터미널에서 `Ctrl + C`.
- 브랜치 하나만 빠르게 보고 싶으면 `python scripts\serve.py --open` (지금 선택된 브랜치만, 탭 없음).

### 2.2 페이지 열기 — 탭으로 모델 고르기

![비교 페이지: 위쪽 탭으로 모델을 바꿔 봅니다](images/02-tabs.png)

- **위쪽 탭**을 누르면 화면이 통째로 바뀝니다. 탭마다 다른 모델(브랜치)입니다.

  | 탭 | 무엇이 다른가 |
  |---|---|
  | 기본 모델 | 교수님 초안 그대로 |
  | 썸네일 착각 | 썸네일만 보고 재미를 잘못 짐작함 |
  | 늦은 깨달음 | 지나간 카드를 뒤늦게 알아차리고 되돌아감 |
  | 화면 붐빔 | 화면에 모르는 카드가 많으면 알아보기가 느려짐 |

- **맨 위 줄**(피드 번호, 누가 조작?, 속도, 같은 조건으로 다시 시작, 모두 재생/멈춤)은 **모든 탭에 한꺼번에** 적용됩니다. 같은 조건에서 모델끼리 비교할 때 씁니다.
- 탭 하나만 크게 보려면 오른쪽 위 **이 탭만 새 창으로 ↗**.
- 주소 끝에 `#3`을 붙이면 세 번째 탭이 바로 열립니다: `http://127.0.0.1:8000/#3`

탭 안의 화면은 이렇게 생겼습니다(기본 모델, 20초 진행 후). 각 부분의 역할은 3장에서 설명합니다.

![한 화면 전체: 왼쪽 휴대폰 화면, 오른쪽 재미 그래프](images/03-page.png)

### 2.3 같은 와이파이(같은 공유기)의 다른 PC에서 열기

```powershell
python scripts\serve_branches.py --host 0.0.0.0
```

- 터미널에 `same network: http://192.168.x.x:8000` 주소가 나옵니다. 다른 PC 브라우저에서 이 주소로 엽니다.
- 처음 한 번은 **관리자 권한 PowerShell**에서 방화벽을 열어야 합니다.
  ```powershell
  New-NetFirewallRule -DisplayName "scrolling-agent demo" -Direction Inbound -Protocol TCP -LocalPort 8000 -Action Allow -Profile Private,Domain
  ```
- 실행할 때 "Python 액세스 허용" 창이 뜨면 **개인 네트워크**만 체크하고 허용합니다.
- `192.168.…` 주소는 **같은 공유기 안에서만** 열립니다. 다른 곳에 있는 팀원은 2.4를 쓰세요. 학교 와이파이도 기기끼리 연결을 막는 경우가 많아 2.4가 필요합니다.

### 2.4 다른 곳에 있는 팀원에게 링크로 공유하기 (Cloudflare 터널)

터미널 두 개가 필요합니다. VS Code 터미널 패널의 **`+`**(또는 `` Ctrl + Shift + ` ``)로 하나 더 엽니다.

```powershell
# 처음 한 번: 터널 프로그램 설치 (설치 후에는 새 터미널을 열어야 인식됩니다)
winget install --id Cloudflare.cloudflared

# 터미널 1: 비밀번호를 걸고 실행
python scripts\serve_branches.py --token 우리팀비번

# 터미널 2: 터널 열기 (venv 필요 없음)
cloudflared tunnel --url http://localhost:8000
```

터미널 2에 이런 상자가 나오면 그 주소가 외부 공개 주소입니다.

```text
|  Your quick Tunnel has been created! Visit it at (it may take some time to be reachable):  |
|  https://xxxx-xxxx-xxxx-xxxx.trycloudflare.com                                             |
```

팀원에게는 **비밀번호를 붙인 주소**를 보냅니다.

```text
https://xxxx-xxxx-xxxx-xxxx.trycloudflare.com/?token=우리팀비번
```

비밀번호 없이 들어오면 아래 화면이 나옵니다. 비밀번호를 넣고 **들어가기**를 누르면 됩니다(한 번 들어오면 브라우저가 기억).

![비밀번호 화면](images/01-login.png)

- 터미널 1, 2를 **둘 다 켜 둬야** 접속됩니다. 끄면 바로 닫힙니다.
- 터널을 다시 켜면 **주소가 바뀝니다** → 새 주소를 다시 공유하세요.
- 처음 1분 정도는 접속이 안 될 수 있습니다. 잠시 후 새로고침.
- `--token` 없이 열면 링크를 아는 누구나 들어올 수 있으니 꼭 비밀번호를 거세요.

### 2.5 주소로 원하는 상태를 바로 열기

공유할 때 "이 장면을 봐" 하고 보내기 좋습니다. 탭 안의 화면 주소(`/b/번호/`) 뒤에 붙입니다.

| 붙이는 것 | 뜻 | 예 |
|---|---|---|
| `scenario=상황이름` | 상황 고르기를 적용하고 행동 비교까지 실행 | `scenario=late` (늦은 깨달음), `scenario=boring_fast` (금방 질림) |
| `skip=숫자` | 그만큼(0.1초 단위) 진행한 장면부터 | `skip=112` → 11.2초 |
| `policy=이름` | 누가 조작할지 | `policy=human` (직접 해 보기) |
| `seed=숫자` | 피드 번호 | `seed=10003` |
| `hidden=1` | 숨은 값 보기 켜기 | |
| `pause=1` | 중요한 순간에 멈춤 켜기 | |
| `autoplay=1` | 열자마자 재생 | |

예: 늦은 깨달음 탭에서 11.2초 장면

```text
http://127.0.0.1:8000/b/3/?scenario=late&skip=112
```

![상황 '아까 그거 괜찮았는데'를 적용한 11.2초 장면과 아래쪽 행동 비교](images/04-scenario-compare.png)

상황 이름 목록은 `webdemo/descriptions.py`의 `SCENARIOS`에 있습니다.

### 2.6 자주 나는 문제

| 증상 | 원인과 해결 |
|---|---|
| `cloudflared`(이)가 인식되지 않습니다 | 설치 안 됨 → `winget install --id Cloudflare.cloudflared` 후 **새 터미널**에서 실행 |
| `Activate.ps1` 실행 오류 | `Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned` 후 다시 |
| `[WinError 10048] 각 소켓 주소(…)는 하나만 사용할 수 있습니다` 또는 `server for … stopped` | 이미 서버가 켜져 있음(포트 사용 중) → 켜져 있는 터미널에서 `Ctrl + C`, 또는 `--port 8100`처럼 다른 번호로 실행 |
| 비밀번호 화면이 계속 나옴 | 주소의 `?token=` 값이 터미널 1의 `--token` 값과 다름 |
| 탭 안이 하얗게 비어 있음 | 터미널 1이 꺼졌거나 아직 시작 중 → 터미널 확인 후 새로고침 |
| 다른 PC에서 안 열림 | 같은 공유기가 아니면 2.3이 아니라 2.4(터널)를 써야 함 |

### 3.3 오른쪽: 재미 그래프 3개

**재미 그래프 3개** — 지금 보는 콘텐츠의 재미, 알아본 후보들의 재미, 세션 전체에서 얻은 점수를 위에서부터 차례로 보여 줍니다.

![기본 모델의 12초 장면: 콘텐츠 #7의 재미 곡선, 알아본 콘텐츠들의 막대, 누적 점수 그래프](images/33-reward-graphs.png)

**① 보고 있는 콘텐츠의 재미**

| 표시 | 뜻 | 이렇게 써 보세요 |
|---|---|---|
| 제목의 `#번호`와 `보는 중` | 지금 열어 보고 있는 콘텐츠의 번호입니다. 목록으로 나오면 마지막으로 본 콘텐츠가 남습니다. | 콘텐츠가 닫힌 뒤 제목이 `마지막으로 본 콘텐츠`로 바뀌는지 확인합니다. |
| 초록 곡선 | 해당 콘텐츠를 오래 볼수록 줄어드는 재미입니다. 가로축은 **그 콘텐츠를 본 누적 시간**, 세로축은 재미의 크기입니다. | `한 스텝 (N)`을 누르며 본 시간이 늘 때 재미가 줄어드는지 봅니다. |
| 빨간 점과 `지금 재미` | 지금까지 본 시간에 해당하는 곡선 위의 위치와 재미입니다. | 빨간 점이 `볼 만한 기준` 점선에 가까워지는지 봅니다. |
| 주황색으로 칠한 넓이와 `얻은 재미` | 이 콘텐츠에서 지금까지 얻은 재미입니다. 매 스텝 비용을 빼기 전 값입니다. | 시청이 이어질 때 색칠된 구간이 오른쪽으로 늘어나는지 확인합니다. |
| `본 시간` | 이 콘텐츠를 실제로 본 시간입니다. 닫았다가 다시 열어도 이전에 본 시간이 이어집니다. | 화면 전체의 경과 시간과 비교합니다. 위 캡처는 세션 12초에 #7을 2.4초 본 장면입니다. |

아직 아무 콘텐츠도 열지 않았다면 `아직 열어 본 콘텐츠가 없습니다.`가 나옵니다. 목록을 훑는 동안에는 이 콘텐츠의 본 시간이 늘지 않습니다.

**② 알아본 콘텐츠들의 지금 재미**

| 표시 | 뜻 | 이렇게 써 보세요 |
|---|---|---|
| 막대의 위치와 높이 | 가로축은 목록에서의 콘텐츠 위치입니다. 높이는 그 콘텐츠의 지금 재미입니다. 아직 알아보지 못한 콘텐츠는 막대가 없습니다. | 휴대폰 화면의 `#번호`와 막대 위치를 맞춰 봅니다. |
| 초록 막대 / 빨간 막대 | 초록은 알아본 콘텐츠, 빨강은 현재 보고 있는 콘텐츠입니다. | 콘텐츠를 열었을 때 해당 막대가 빨강으로 바뀌는지 봅니다. |
| 파란 배경 / 파란 테두리 | 파란 배경은 현재 목록 화면의 범위입니다. 파란 테두리는 현재 화면의 선택 가능한 카드입니다. | 목록을 내릴 때 파란 영역이 이동하는지 봅니다. |
| 막대 위 주황색 선 | 실제로 본 적이 있는 콘텐츠입니다. | 닫고 목록으로 돌아온 뒤에도 표시가 남는지 봅니다. |
| `볼 만한 기준` 점선 | 위쪽 조작 막대의 **볼 만한 기준 ρ**입니다. 이 기준을 쓰는 정책은 기준 이상의 후보를 열고, 보던 콘텐츠의 재미가 기준 아래로 내려가면 닫습니다. | `greedy`에서 점선과 빨간 막대 높이를 비교합니다. |

점선은 `scrollfirst`, `greedy`, `greedy-dwell`에서만 나옵니다. ρ를 바꿔 실제 행동을 비교하려면 **다시 시작 (R)**을 눌러 새 기준을 적용하세요. `늦은 깨달음` 탭에서는 지나간 뒤 알아챈 콘텐츠의 막대 위에 노란 `★`도 붙습니다.

**③ 지금까지 얻은 재미 (초록 = 보는 중)**

| 표시 | 뜻 | 이렇게 써 보세요 |
|---|---|---|
| 가로축 `시간 0 ~ 120초` | 세션 시작부터 흐른 시간입니다. 기본 세션은 120초이며, 설정을 바꾸면 축의 끝도 바뀝니다. | 첫 번째 그래프의 `본 시간`과 구분해서 읽습니다. |
| 검은 선 | 모든 콘텐츠에서 얻은 재미를 합하고, 지금까지의 매 스텝 비용을 뺀 누적 점수입니다. 아래 상태 표의 `얻은 재미 (점수)`와 같은 값입니다. | 현재 선의 끝과 상태 표의 점수를 함께 확인합니다. |
| 연한 초록 배경 | 콘텐츠를 보는 중인 구간입니다. | 초록 구간에서 점수가 얼마나 올라가는지 봅니다. |
| 선이 내려가는 구간 | 목록을 보거나 여닫는 동안에도 비용이 들기 때문에 점수가 줄 수 있습니다. 시청 중에도 얻는 재미가 비용보다 작으면 줄어듭니다. | 콘텐츠를 닫은 뒤 다음 것을 찾는 구간을 관찰합니다. |

**이렇게 써 보세요**

1. `기본 모델` 탭에서 상황을 `기본 (교수님 초안 설정)`, 정책을 `greedy`, ρ를 `0.6`, seed를 `10000`으로 맞춥니다. **다시 시작 (R)**을 누르고 재생합니다.
2. 콘텐츠가 열리면 일시정지하고 **한 스텝 (N)**으로 진행합니다. 첫 번째 그래프의 빨간 점과 주황색 넓이, 두 번째 그래프의 빨간 막대를 함께 봅니다.
3. 콘텐츠가 닫히면 첫 번째 그래프의 제목과 세 번째 그래프의 점수 변화를 확인합니다.

캡처와 같은 12초 장면은 2.1의 비교 서버를 기본 포트로 실행한 뒤 아래 주소로 열 수 있습니다. dwell은 `0.5`이며, `greedy`에서는 사용하지 않습니다.

```text
http://127.0.0.1:8000/b/1/?scenario=base&policy=greedy&seed=10000&rho=0.6&dwell=0.5&skip=120&hidden=0&pause=0
```

**알아 두면 좋은 점**: 위 두 그래프는 에이전트가 알고 있는 재미를 보여 줍니다. `썸네일 착각` 확장을 켰다면 실제 재미와 다를 수 있습니다. **숨은 값 보기 (H)**를 켜면 첫 번째 그래프의 빨간 점선과 두 번째 그래프의 빨간 점으로 실제 값을 함께 볼 수 있습니다. 세 번째 그래프는 실제로 받은 보상과 비용으로 계산한 점수입니다.

### 3.4 상태 표와 일어난 일

**상태 표와 일어난 일** — 현재 실행의 누적 수치와, 콘텐츠를 알아보고 열고 닫은 순서를 확인하는 곳입니다. 재미 그래프 3개 바로 아래에 있습니다.

![기본 모델의 12초 장면: 상태 표의 점수·횟수·시간과 콘텐츠를 알아보고 여닫은 기록](images/34-state-events.png)

**상태 표 읽기**

| 표시 | 뜻 | 이렇게 써 보세요 |
|---|---|---|
| 지금 | `목록 보는 중`, `#번호 보는 중`, `여닫는 중` 중 현재 상태입니다. | 카드를 열거나 닫을 때 상태가 바뀌는지 확인합니다. |
| 얻은 재미 (점수) | 시청으로 얻은 재미에서 지금까지의 매 스텝 비용을 뺀 점수입니다. | 바로 위 누적 점수 그래프의 끝과 비교합니다. |
| 본 것에서 얻은 재미 | 지금까지 실제로 본 모든 콘텐츠에서 얻은 재미의 합입니다. 비용을 빼기 전 값입니다. | `얻은 재미 (점수)`와의 차이를 봅니다. |
| 뭔지 알아본 수 | 썸네일을 보고 무엇인지 알아낸 콘텐츠 수입니다. 아직 열지 않은 것도 포함합니다. | `뭔지 알아봄` 기록이 생길 때 숫자가 늘어나는지 봅니다. |
| 열어 본 횟수 | 콘텐츠를 연 횟수입니다. 같은 콘텐츠를 다시 열어도 한 번 더 셉니다. | `#번호 열기` 기록과 함께 확인합니다. |
| 목록을 본 시간 | 목록에서 스크롤하거나 멈춰서 살펴본 시간의 합입니다. | 목록을 내리는 동안 값이 늘어나는지 봅니다. |
| 콘텐츠를 본 시간 | 콘텐츠를 실제로 시청한 시간의 합입니다. 여닫는 시간은 제외합니다. | 콘텐츠를 연 뒤 이 값이 늘어나는지 봅니다. |
| 여닫는 데 쓴 시간 | 콘텐츠를 열고 목록으로 돌아오는 전환에 쓴 시간의 합입니다. | 자주 열고 닫을수록 얼마나 늘어나는지 봅니다. |
| 방금 한 행동 | 가장 최근 한 스텝의 행동입니다. `아래로`, `위로`, `멈춤`, `1번 카드 열기`, `닫고 목록으로` 등이 나옵니다. | **한 스텝 (N)**을 누르며 읽습니다. 시청 중 `멈춤`은 영상을 계속 보는 행동입니다. |

위 캡처에서 점수는 **4.69**, 본 것에서 얻은 재미는 **5.89**입니다. 기본 설정에서는 0.1초마다 비용 0.01이 들어, 12초 동안 쌓인 비용 **1.20**만큼 차이가 납니다. 세 가지 시간도 **4.8 + 5.8 + 1.4 = 12.0초**로 세션 경과 시간과 같습니다.

**일어난 일 읽기**

기록은 **최근 일이 맨 위**에 나옵니다. 왼쪽의 `6.1s` 같은 숫자는 세션 시작 후 몇 초에 일어났는지를 뜻합니다. 기록이 길어지면 이 영역 안에서 스크롤해 이전 내용을 볼 수 있습니다. 화면에는 최근 최대 60개가 표시됩니다.

| 표시 | 뜻 | 이렇게 써 보세요 |
|---|---|---|
| `#번호 뭔지 알아봄` | 콘텐츠가 무엇인지 알아낸 순간입니다. 알아봤다고 바로 여는 것은 아닙니다. | 같은 번호의 `열기` 기록이 뒤이어 생기는지 확인합니다. |
| **노란 배경**의 `지나간 뒤에 뒤늦게!` | 목록에서 지나간 콘텐츠를 화면 밖에서 뒤늦게 알아챘습니다. | `늦은 깨달음` 탭에서 해당 번호를 기억하고 다음 행동을 봅니다. |
| **주황 글씨**의 `#번호 열기` | 그 콘텐츠를 여는 행동입니다. | 상태 표의 `열어 본 횟수`가 늘어나는지 확인합니다. |
| `← 뒤늦게 알아챈 콘텐츠로 되돌아옴` | 지나친 뒤 알아챈 콘텐츠로 돌아와 열었습니다. | 앞선 노란 기록과 콘텐츠 번호를 맞춰 봅니다. |
| `(다시 보기)` | 실제로 본 적 있는 콘텐츠를 다시 열었습니다. | 단순히 지나쳤다가 처음 여는 경우와 구분합니다. |
| `#번호 닫음 (…초 봄)` | 콘텐츠를 닫는 행동입니다. 괄호는 해당 콘텐츠의 누적 시청 시간입니다. | 같은 콘텐츠를 여러 번 봤다면 이전 시청 시간도 포함됨을 기억합니다. |
| 빨간 글씨의 `지금은 … 할 수 없어 멈춤` | 현재 상태에서 할 수 없는 행동을 요청해 `멈춤`으로 처리했습니다. | 직접 조작할 때 현재 상태와 선택 가능한 카드를 확인합니다. |

`#3`은 피드 안의 콘텐츠 번호입니다. `방금 한 행동`의 `1번 카드 열기`는 **현재 화면에 붙은 조작 번호**이므로 두 숫자가 달라도 정상입니다. 일어난 일에는 주요 사건만 기록되며, 매 스텝의 스크롤이나 멈춤이 모두 나오지는 않습니다.

**늦은 깨달음 예시**

![늦은 깨달음의 6.2초 장면: 5.9초에 #3을 뒤늦게 알아챈 노란 기록과 6.1초에 돌아와 연 주황색 기록](images/34-late-events.png)

이 장면은 `늦은 깨달음` 탭에서 상황을 `아까 그거 괜찮았는데 (늦은 깨달음) [확장]`으로 고른 결과입니다. 이 상황은 **지나간 뒤에도 생각나는 시간**을 `0 → 2초`로 바꿉니다. 위쪽 주황 기록은 **6.1초에 #3을 열었음**, 그 아래 노란 기록은 **5.9초에 #3을 뒤늦게 알아챘음**을 보여 줍니다.

이 탭의 상태 표에는 다음 세 줄이 추가됩니다. 다른 확장 탭에서는 해당 기능의 지표가 추가될 수 있습니다.

| 추가 표시 | 뜻 | 이렇게 써 보세요 |
|---|---|---|
| 지나간 뒤에 알아차린 수 | 스크롤로 지나친 뒤 화면 밖에서 알아챈 콘텐츠 수입니다. | 노란 기록의 서로 다른 콘텐츠 번호를 세어 봅니다. |
| 다른 걸 보는 동안 알아차린 수 | 콘텐츠를 시청하거나 여닫느라 목록이 가려진 동안 알아챈 콘텐츠 수입니다. | 해당 처리가 켜져 있을 때 관찰합니다. 위 캡처에서는 `0.00`입니다. |
| 늦게 깨닫고 되돌아가 연 횟수 | 지나친 뒤 알아챈 콘텐츠를 연 횟수입니다. | `되돌아옴`이 붙은 주황 기록과 비교합니다. |

**이렇게 써 보세요**: 아래 주소로 6.2초 장면을 연 뒤 노란 줄과 주황 글씨의 `#3`을 비교하세요. **한 스텝 (N)**으로 진행하면 `여닫는 중`에서 `#3 보는 중`으로 바뀌는 과정도 볼 수 있습니다. 정책은 `greedy`, ρ는 `0.6`, seed는 `10000`, dwell은 `0.5`이며 `greedy`에서는 dwell을 사용하지 않습니다.

```text
http://127.0.0.1:8000/b/3/?scenario=late&policy=greedy&seed=10000&rho=0.6&dwell=0.5&skip=62&hidden=0&pause=0
```

**알아 두면 좋은 점**: 상태 표는 현재 피드 한 번의 진행 수치입니다. 아래쪽 `행동 비교`의 여러 피드 평균과 구분하세요. **다시 시작 (R)**을 누르면 상태 수치와 사건 기록도 처음부터 시작합니다.

## 4. 이 문서에 추가하는 방법

### 4.1 화면 캡처하기

1. 2.1처럼 데모를 실행하고, 보여 주고 싶은 장면을 만듭니다. 2.5의 주소(`skip=`, `scenario=`)를 쓰면 같은 장면을 다시 만들기 쉽습니다.
2. **`Win + Shift + S`** → 사각형으로 원하는 부분을 선택 → 오른쪽 아래 알림을 눌러 **저장**(PNG).
3. 파일을 `docs/guide/images/`에 넣습니다.
   - 이름은 **절 번호 + 짧은 영어**: `31-controls.png`, `32-phone-card.png`, `35-compare-table.png`
   - 너무 크면 읽기 힘드니 화면 일부만 잘라 주세요(가로 1600픽셀 이하 권장).
4. 문서에는 `![설명](images/파일이름.png)` 한 줄로 넣습니다. 설명은 그림이 안 보일 때 대신 읽히는 문장입니다.
5. 화살표나 번호를 그려 넣고 싶으면 캡처 도구(또는 그림판)에서 그린 뒤 저장하면 됩니다. 원본과 표시본을 구분하려면 `-annotated`를 붙입니다.

- **쉬운 말**로 씁니다. 화면에 보이는 이름 그대로("볼 만한 기준", "알아봄") 쓰고, 전문용어(DDM, drift, λ)는 피합니다. 꼭 필요하면 괄호로 한 번만.

- "이렇게 써 보세요"처럼 **직접 해 볼 수 있는 한 가지**를 꼭 넣습니다(무엇을 바꾸고 무엇을 보면 되는지).
